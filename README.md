# Travel Booking Website Automation Framework

## Project Overview
This project is an end-to-end Selenium automation framework developed to automate key user journeys of a travel booking web application.  
It is designed using real-world QA automation best practices and is suitable for automation testing roles.

The framework focuses on maintainability, scalability, and reliability using industry-standard design patterns.

---

## Tech Stack
- Java  
- Selenium WebDriver  
- TestNG  
- Maven  
- Eclipse IDE  

---

## Framework Design
- Page Object Model (POM)
- Data-driven testing using TestNG DataProvider
- TestNG Listeners for failure handling
- Automatic screenshot capture on test failure
- Reusable utility classes for common actions
- Centralized browser and test setup

---

## Automated Scenarios
- Flight search functionality
- City selection and validation
- Date selection using calendar controls
- End-to-end booking flow
- Fare calculation and summary validation
- Confirmation page validation
- Screenshot capture on test failure

## How to Run Tests
1. Clone the repository  
2. Import the project as a **Maven project** in Eclipse  
3. Ensure Java and Maven are configured  
4. Run `testng.xml` or individual TestNG test classes  
5. View execution results in **test-output** folder
